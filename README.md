# Evil8 Helm Charts

Public Helm charts, published as OCI artifacts to `ghcr.io/evil8io/charts`.

## Usage

```bash
helm install <release> oci://ghcr.io/evil8io/charts/<chart> --version <version>
```

## Charts

Each chart is in its own directory under [`charts/`](charts).

The published versions of each chart are on the [releases page](https://github.com/evil8io/charts/releases).
